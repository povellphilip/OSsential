OSsentinal — PRO Node-Free Edition

Run by double-clicking index.html. No Node.js, npm, server or backend required.

Designed as an academic OS experimentation platform rather than a collection of basic calculators.

Core modules:
- Banker's Algorithm
- Memory Allocation
- Page Replacement
- TLB / EAT
- Segmentation
- Peterson's Algorithm

Novel integration features:
1. OS System Twin — models workload pressure and identifies the dominant bottleneck.
2. Adaptive Policy Engine — converts workload characteristics into coordinated recommendations.
3. What-If Lab — controlled experiments comparing policies under changed resource constraints.
4. System Report — generates a downloadable experiment report.
5. Cross-module architecture — Input → Simulation → Metrics → Bottleneck Analysis → Recommendation.

The System Twin is explicitly a simulation model, not a live monitor of the user's computer.
